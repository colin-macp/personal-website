Web Application - AWS Wildrydes

This project is a simple web application built using AWS services. The application architecture includes: Fronted — HTML, CSS, and JavaScript using static website hosting on S3. Backend — AWS Lambda functions for serverless computing connected to DynamoDB for data storage and linked to the fronted through API Gateway. Authentication — AWS Cognito for user authentication and management.

Services Used: S3, lambda, Cognito, IAM, API Gateway, DynamoDB, CloudWatch
